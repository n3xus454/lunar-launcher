# Guide de contribution

## Regles importantes

1. Aucune ROM ni BIOS ne doit etre ajoute.
2. Aucun asset copyrighte ne doit etre ajoute.
3. Le code doit etre teste avant soumission.

## Comment contribuer

1. Fork le projet
2. Cree une branche
3. Commit tes changements
4. Push
5. Ouvre une Pull Request
