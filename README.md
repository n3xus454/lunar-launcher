# Lunar Launcher

Un launcher multi-consoles pour emulateurs retro.

## Prerequis

- Python 3.11+
- PyQt6
- RetroArch avec les cores appropries

## Installation

    git clone https://github.com/n3xus/lunar-launcher.git
    cd lunar-launcher
    pip install -r requirements.txt
    python launcher.py

## Important : ROMs et BIOS

Ce projet ne fournit AUCUNE ROM ni AUCUN BIOS.
Tu dois posseder legalement les jeux que tu utilises.
